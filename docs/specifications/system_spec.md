## 1. 项目概述

**BanSafe** 是一款基于 ESP32-S3-EYE 的多传感器融合室内安全监控设备。

### 1.1 核心功能

| 功能 | 当前状态 | 优先级 |
|------|----------|--------|
| 姿态异常检测（加速度计） | ✅ 已实现 | P0 |
| 音频异常分析（麦克风） | ❌ 规划中 | P1 |
| 视觉异常分析（摄像头+TFLite） | ❌ 规划中 | P1 |
| Wi-Fi 通信与云端上报 | ❌ 规划中 | P1 |
| 三重判定引擎 | ✅ 已实现（阶段1可用） | P0 |
| BLE 室内定位 | ❌ 规划中 | P2 |
| OTA 固件升级 | ❌ 规划中 | P2 |
| LCD 本地显示 | ❌ 规划中 | P3 |

> **变更说明（v0.1.0）**：原规格中声称"已实现 BLE 定位"和"三重判定引擎完整"描述与代码实际状态不一致，已修正为上述真实状态。

### 1.2 硬件平台

| 组件 | 型号 | 接口 |
|------|------|------|
| MCU | ESP32-S3-WROOM-1 | — |

## 3. 三重判定引擎规范

### 3.1 判定逻辑

三重"与"逻辑：只有当**姿态、音频、视觉**三个阶段的评分**均超过阈值**时，才触发最终报警。

### 3.2 阈值配置

| 阶段 | 阈值 | 评分范围 | 说明 |
|------|------|----------|------|
| 阶段1-姿态 | ≥40 | 0-100 | 基于加速度矢量偏离 1g 的程度 |
| 阶段2-音频 | ≥60 | 0-100 | **规划中** — MFCC 特征 + TFLite |
| 阶段3-视觉 | ≥80 | 0-100 | **规划中** — TFLite Micro 推理 |

### 3.3 阶段1姿态检测算法

- 输入：加速度计三轴数据 (mg)
- 计算：`magnitude = sqrt(x² + y² + z²)`
- 异常度量：`deviation = |magnitude - 1000|` (正常静止时接近 1g = 1000 mg)
- 评分映射：`score = min(100, max(0, deviation / 20))`
